# FLOAT.

컬러와 도형이 천천히 부유하는 인터랙티브 컬러 플레이그라운드입니다.

## 실행

`index.html`을 브라우저에서 열거나 VS Code Live Server로 실행하세요. 프레임워크나 빌드 과정은 필요하지 않습니다. Matter.js를 CDN에서 불러오므로 최초 접속에 인터넷 연결이 필요합니다.

## 조작

- 도형은 PC에서 5열 × 3행으로 15개, 모바일에서 3열 × 4행으로 12개 배치됩니다. 모바일 도형 너비는 36vw입니다.
- Gravity 모드에서는 도형을 마우스나 터치로 잡아 끌고 놓을 수 있습니다. 놓으면 중력에 따라 떨어집니다.
- 다른 모드에서는 화면을 클릭하거나 터치하면 해당 지점에서 주변 도형이 강하게 흩어집니다. 커서 이동에는 반응하지 않습니다.
- Interaction: Float / Repel / Attract / Scatter / Gravity / Bounce
- Blending: 18가지 블렌딩 모드 중 현재 브라우저가 지원하는 항목만 표시합니다.
- 도형 색상 알파값은 0.6이며, Normal 모드에서만 도형 배경에 12px 블러를 적용합니다. 헤더에는 항상 배경 블러를 적용합니다.
- 도형은 화면 끝까지 이동합니다. 우측 하단 조절 버튼을 누르면 자동 높이·최대 화면의 70%인 설정 패널이 열립니다. 제목을 아래로 끌거나 외부 영역을 누르면 닫힙니다.
- 시스템의 동작 줄이기 설정에서는 움직임 속도를 낮춥니다.
- 우측 하단 설정 아이콘 버튼으로 패널을 열고 인터랙션과 블렌딩 모드를 선택합니다. 도형 크기는 50~150%, 개수는 3~30개로 슬라이더에서 조절합니다. 기존 도형 위치와 선택 모드는 유지됩니다. 닫기 버튼이나 Esc로 패널을 닫을 수 있습니다.

## 파일

- `index.html`: 페이지
- `js/app.js`: Matter.js 물리 계산, DOM 렌더링, UI 이벤트
- `scss/`: 리셋, 변수, 믹스인, 메인 SCSS
- `scss/style.css`: 브라우저용 CSS

CSS 컴파일은 VS Code에 설치된 Live Compilation 확장프로그램을 사용합니다. `scss/style.scss`를 저장하면 같은 폴더의 `style.css`로 출력하도록 설정합니다. CLI 컴파일은 사용하지 않습니다.

컬러 레퍼런스 이미지가 제공되지 않아 10가지 미드센츄리 계열 색상을 적용했습니다. 팔레트는 `scss/_variables.scss`의 `$palette`에서 변경합니다.

성능 점검 방법과 측정 범위는 `PERFORMANCE.md`를 참고하세요.
